# KoreanLearn

বাংলাভাষী শিক্ষার্থীদের জন্য কোরিয়ান ভাষা শেখার সম্পূর্ণ স্ট্যাটিক ওয়েবসাইট। কোনো লগইন নেই, কোনো সার্ভার নেই — সব প্রোগ্রেস ব্রাউজারের localStorage-এ সেভ হয়।

## ফিচার

- **ভোকাবুলারি** — ১৫টি ক্যাটাগরি, প্রতিটি শব্দে কোরিয়ান, বাংলা উচ্চারণ, বাংলা+ইংরেজি অর্থ, উদাহরণ বাক্য, সাউন্ড, কঠিন শব্দ, শিখে ফেলেছি বাটন
- **রিডিং প্র্যাকটিস** — ৩ লেভেলের প্যারাগ্রাফ, শব্দে ট্যাপে অর্থ পপআপ, বাক্য হাইলাইটসহ অডিও, MCQ কুইজ
- **ফ্ল্যাশকার্ড** — জানি/জানি না ভিত্তিক সহজ স্পেসড রিপিটিশন
- **কুইজ** — ৩ ধরনের ১০ প্রশ্নের রাউন্ড
- **হাঙ্গুল চার্ট** — স্বরবর্ণ/ব্যঞ্জনবর্ণ + "অক্ষর চেনো" গেম
- **স্ট্যাটস** — স্ট্রিক, শেখা শব্দ, ৭ দিনের চার্ট, ব্যাজ
- **সার্চ** — কোরিয়ান/বাংলা/ইংরেজি যেকোনো ভাষায়
- **সেটিংস** — ফন্ট সাইজ, ডেইলি গোল, Export/Import ব্যাকআপ
- **PWA** — মোবাইলে ইনস্টল করা যায়, অফলাইনেও চলে

## পেজ

| পেজ | কাজ |

| index.html | হোম: ডেইলি ওয়ার্ড, স্ট্রিক, গোল প্রোগ্রেস, সার্চ |
| vocabulary.html | সব শব্দ, ভাষা ফিল্টার, লেজি লোডিং |

| quiz.html | কুিজ রাউন্ড |
| hangul.html | হাঙ্গুল চার্ট + গেম |
| stats.html | স্ট্যাটস, চার্ট, ব্যাজ |

## নতুন ক্যাটাগরি যোগ করা

1. `data/vocab/` ফোল্ডারে নতুন JSON ফাইল রাখুন
2. `data/categories.js`-এ এক লাইন যোগ করুন
3. সব পেজে নতুন ক্যাটাগরি নিজে থেকেই দেখাবে

শব্দের ফরম্যাট:

```json
{ "id": "body-001", "ko": "머리", "pron": "মরি", "bn": "মাথা", "en": "head",
  "example": { "ko": "머리가 아파요.", "bn": "আমার মাথা ব্যথা করছে।", "en": "My head hurts." } }
```

## লোকাল রান

```bash
npx serve .
```

(ভোকাবুলারি JSON `fetch` করা হয়, তাই `file://`-এ সরাসরি খুললে শব্দ আসবে না।)

## ডেপ্লয়

রিপো Settings → Pages → Source: `dev` বা `main` ব্রাঞ্চ, `/ (root)` → Save। কিছুক্ষণ পরে লাইভ:
`https://foyaj1234.github.io/KoreanLearn/`
